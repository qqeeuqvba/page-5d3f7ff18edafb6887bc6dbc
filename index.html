常见问题

云深不知处官网如何选择并下载客户端？

先根据系统选择 Clash 兼容客户端：Windows 用 Clash Verge 等，Android 用 Clash Meta，iOS 用 Shadowrocket 或 Stash，macOS 用 ClashX Meta 或 Surge。软件从官方商店或开发者发布渠道安装，本站提供导入教程而非来路不明的安装包。装好后到用户中心复制订阅即可。

机场订阅链接怎样导入才稳定？

打开客户端的订阅/配置管理，选择“从 URL 添加”，完整粘贴面板中的订阅地址，保存并更新。不要把链接发到公开群。若更新超时，可更换网络后重试，或在客户端中设置超时与 UA。导入成功后应能看到按地区分组的节点。

基础版、旗舰版和团队版怎么选？

轻度浏览与基础流媒体选基础版（100GB / 3 设备）。需要原生解锁、游戏 IPLC 和优先工单选旗舰版（300GB / 5 设备）。多人共用、高带宽与定制路由选团队版（1000GB / 20 设备）。年付价格已在各卡片标明。

能否用于 Netflix、ChatGPT 等服务？

基础版覆盖基础流媒体。旗舰版与团队版强调全节点原生解锁，并定期维护可用性。生成式服务与流媒体对 IP 质量敏感，遇到验证时更换同地区备用节点，不要短时间高频切换。

连上后速度慢或打不开怎么办？

依次尝试：更换节点、开启 TUN、关闭其他代理软件、检查系统时间、暂时关闭防火墙试一次。游戏走专线组，下载可走高带宽组。若全部节点失败，提交工单并注明客户端版本与错误信息。

如何确认自己在使用云深不知处官方服务？

认准品牌名云深不知处(ysbzc)及本官方网站信息架构。订阅只在登录后的用户中心显示。我们不会通过陌生即时通讯索要密码。客户端应来自公开可信来源，配置里仅包含您自己的订阅 URL。
